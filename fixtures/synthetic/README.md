## Privacy marker

synthetic-year-2025.xlsx holds four consecutive readings on 2025/06/15 ending at 12:15, 12:30, 12:45, 13:00
with the values 9,871, 9,872, 9,873, 9,874 kW. Synthetic readings never exceed 5.5 kW,
so these values appear nowhere else. A leak detector searches for these kW values only (`YEAR_LEAK_NEEDLES`
in the generator), never for derived kWh values, which ordinary readings can also produce.
